## How Video Integration Works

### Video Moments in Each Coach Session

Each coach has 3 key video moments integrated into the A3 experience:

#### 1. Greeting Phase (Introduction)
- Coach appears on screen and introduces themselves
- Sets the interview context and tone
- Explains what they'll be evaluating
- Creates psychological safety or challenge depending on level
- Example: Sofia's greeting is warm and welcoming; Jordan's is more probing

#### 2. Thinking Pauses (Between Questions)
- After candidate responds, coach appears to "think" about the response
- This video creates natural pacing and authenticity
- Coach's facial expressions show their evaluation process
- Builds tension/encouragement based on coach personality
- Example: Elena nods thoughtfully; Marco looks intensely analytical

#### 3. Farewell Phase (Closing)
- Coach summarizes their assessment
- Provides personalized feedback
- Explains the score/evaluation rationale
- Offers coaching or mentorship guidance
- Example: Sofia is encouraging; Jordan is insightful and developmental

## User Experience Flow

1. **User opens task** in A2-Routes (e.g., Day 42)
2. **Modal shows** task details with "Practicar con Avatar" button (if recommended)
3. **User clicks button** → Redirected to A3 with pre-selected coach (Elena for Day 42)
4. **A3 simulation**:
   - Coach's greeting video plays automatically
   - User reads and responds to interview questions
   - Coach's thinking video plays while system processes response
   - AI evaluation (Marco's prompt) generates personalized feedback
   - Coach's farewell video plays with tailored feedback
5. **Score saved** to track progress across coaches
6. **User returns** to A2-Routes enriched with interview practice

## Technical Implementation

### Avatar Config Mapping
- `lib/avatar-config.ts`: Maps coaches to curriculum days
- Function: `getRecommendedAvatars(day)` returns coach ID for that day
- Function: `getAvatarConfig(avatarId)` returns full coach config + video paths

### Task Modal Integration
- `components/task-detail-modal.tsx`: Shows "Practicar con Avatar" button
- Button is conditional: only appears for days with recommended coaches
- Links to A3 with coach pre-selected via URL param

### Video Playback in A3
- Handled by existing `ConversationalInterview` component
- Uses coach ID to fetch video URLs from avatar config
- Videos play at greeting, thinking, and farewell moments
- Fallback handling if videos don't load

## Progression Logic

**Difficulty Progression:**
- Mes 1 (Sofia): Básico - Build confidence, practice communication
- Mes 2 (Marco, Elena, David): Intermedio - Expose to different perspectives, technical depth
- Mes 3 (Alex, Jordan): Avanzado - Master cross-functional and executive presence

**Coaching Progression:**
- Sofia: Supportive, builds confidence
- Marco/Elena/David: Challenging but professional perspectives
- Alex/Jordan: Advanced coaching, transformational feedback

**Video Tone Progression:**
- Early: Encouraging, welcoming, safe
- Mid: Professional, analytical, challenging
- Late: Mentoring, developmental, transformational

## Success Metrics

Users track their interview practice across coaches:
- Sofia score (baseline confidence)
- Technical score with Marco/David
- Strategic score with Elena/Alex
- Executive presence score with Jordan
- Progress visualization showing growth across coaches
