- Tras #177, el dominio productivo seguía sirviendo temporalmente el artefacto de #176 aunque `main` ya contenía el hotfix. Esta actualización documental crea un árbol nuevo de `main` para exigir una publicación Production fresca sin modificar lógica de aplicación.
- Las migraciones Supabase permanecen versionadas en Git pero **no se consideran aplicadas a DTCFINAL** hasta verificación remota explícita. Mergear código no equivale a ejecutar DDL remoto.
- `main` permanece sin protección de rama en la última comprobación; esto no invalida el código validado, pero sí queda como deuda de gobernanza antes de declarar cierre 9,7.

## Criterio de 9,7

La nota 9,7 exige que todos los ítems marcados como bloqueadores estén `verified`. Un CI verde o una prueba local, aunque use navegador/Auth/PostgREST reales, no sustituye por sí sola una verificación live explícitamente exigida por el gate. No se rebaja seguridad ni se marcan migraciones remotas como aplicadas sólo para completar evidencia.
