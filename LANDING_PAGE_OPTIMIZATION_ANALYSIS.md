PRIORITY 3: IMPROVE HERO CTA VISUAL HIERARCHY
─────────────────────────────────────────────────────────────────────────────

CURRENT: Two buttons side by side ("Diagnóstico Gratuito" and "Ver cómo funciona")
PROBLEM: Users confused about which button to click first
         Secondary CTA steals clicks from primary conversion path

SOLUTION A (Conservative):
- Keep "Diagnóstico Gratuito (5 min)" as prominent PRIMARY button
- Change "Ver cómo funciona" to smaller link/secondary button
- Psychology: Primary action should be 3x more prominent

SOLUTION B (Aggressive):
- Single primary CTA: "Diagnóstico Gratuito (5 min)"
- Move "Ver cómo funciona" to below fold as section heading
- Forces users through full value prop before showing "how it works"
- Psychology: Fewer choices = higher conversion (choice paralysis)

RECOMMENDED: Solution B (Higher conversion lift expected)
