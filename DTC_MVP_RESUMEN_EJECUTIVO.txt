TECNOLOGÍA E INNOVACIÓN
================================================================================

Innovación Clave: IA Adaptativa Contextual

La plataforma utiliza machine learning para personalizar 100% la experiencia
del usuario. Cada usuario recibe un journey único basado en:

• Perfil DISC (personalidad profesional)
• Objetivo profesional específico
• Desempeño en módulos anteriores
• Patrones de interacción
• Feedback recibido

El sistema APRENDE de cada interacción y mejora las recomendaciones en 
tiempo real.

Stack Tecnológico:
├── Frontend:  Next.js 16, React 19, TypeScript, Tailwind CSS
├── Backend:   Next.js API Routes, Serverless Functions
├── BD:        Supabase (PostgreSQL) con RLS
├── IA:        Vercel AI SDK + Azure OpenAI
└── Hosting:   Vercel Edge Network (Global CDN)

Seguridad:
├── Row Level Security (RLS) - Cada usuario solo ve sus datos
├── CORS - Prevención de ataques de origen cruzado
├── Headers de Seguridad - HSTS, CSP, X-Frame-Options
├── Autenticación - Supabase Auth con JWT
└── Encriptación - HTTPS en todos los endpoints
