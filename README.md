> Unauthorized use, copying, distribution, or derivative work is prohibited.

A comprehensive career development platform built with Next.js, featuring AI-powered coaching, skills assessment, and personalized career guidance.

## Features

- AI-powered career coaching
- Skills assessment and evaluation
- CV builder with professional templates
- Interview simulator
- Job search and matching
- Progress tracking and analytics

## Tech Stack

- **Framework**: Next.js (App Router)
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Language**: TypeScript

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install` (or `pnpm install`)
3. Set up environment variables (see `.env.example`)
4. Run the development server: `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000)

## Environment Variables

See `.env.example`.

## Database Setup

Run the SQL scripts in the `scripts/` directory in order to set up the database schema.
