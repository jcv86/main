OPTION B: FFMPEG (FOR DEVELOPERS)
─────────────────────────────────

Prerequisites: FFmpeg installed on your computer

Mac (Homebrew):
  brew install ffmpeg

Linux (Ubuntu/Debian):
  sudo apt-get install ffmpeg

Windows:
  Download from: https://ffmpeg.org/download.html
  Add to PATH


Command to Create Video:
────────────────────────

cd mvp-video-final

Create a file called "concat.txt" with this content:
───────────────────────────────────────────────────

file '01-homepage.png'
duration 8
file '02-login.png'
duration 10
file '03-dashboard.png'
duration 16
file '04-readiness-score.png'
duration 18
file '05-90day-route.png'
duration 21
file '06-training-modules.png'
duration 20
file '07-executive-dashboard.png'
duration 17
file '08-next-tasks.png'
duration 10


Run FFmpeg:
───────────

ffmpeg -y -f concat -safe 0 -i concat.txt \
  -c:v libx264 -pix_fmt yuv420p -r 30 \
  "MVP_Despega_Tu_Carrera_120s.mp4"


Output:
───────
✅ MVP_Despega_Tu_Carrera_120s.mp4 (ready to upload!)

⏱️ Time: ~2 minutes after FFmpeg is installed

TROUBLESHOOTING

Problem: "Extract won't work"
Solution: Use 7-Zip (Windows) or Archive Utility (Mac)

Problem: "Kapwing is slow"
Solution: Try FFmpeg locally or Wave.video instead

Problem: "Can't install FFmpeg"
Solution: Use Kapwing or online tools (no installation needed)

Problem: "YouTube says video is unlisted"
Solution: Go to YouTube Studio → Details → Change Privacy to PUBLIC

Problem: "Video duration is wrong"
Solution: Check timing in concat.txt or Kapwing settings

Problem: "Some screens are missing"
Solution: Re-upload all 8 PNG files in correct order
