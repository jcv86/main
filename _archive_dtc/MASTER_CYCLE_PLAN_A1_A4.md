# PLAN MAESTRO: EL CICLO A1→A2→A3→A4
## Transformación Profesional Intuitiva, Elegante, Fácil y Certera

---

## VISIÓN GENERAL

El ciclo es un **viaje de transformación de 90 días** donde el usuario:
1. **A1** (Semana 1): Descubre quién ES (autoconocimiento)
2. **A2** (Semanas 2-4): Decide quién QUIERE SER (plan de acción)
3. **A4** (Semanas 2-4 paralelo): Entiende el CONTEXTO (mercado y oportunidades)
4. **A3** (Semanas 5-12): Practica SIENDO (entrenamientos intensivos)

**Principio clave**: Cada fase construye sobre la anterior sin fricción, creando momentum.

## 2. FLUJO POR FASE - DETALLES

### A1: EL ESPEJO (1 semana)
**Objetivo**: "Conócete a ti mismo"

**User Journey**:
1. Login / Signup
2. Quiz corto (5 min): "¿Cómo es tu estilo de trabajo?"
3. Acceso a 6 tests científicos
4. Completa tests a su ritmo (pueden ser en varios días)
5. Sistema muestra resultados inmediatos
6. Coach IA personalizado analiza y explica
7. **CTA final**: "Veamos un plan para ti → A2"

**Diseño UX**:
- Progreso visual (qué tests completó)
- Resultados en tarjetas coloridas y claras
- Coach explica sin juzgar
- Botón prominente: "Ir a A2"

**Success Metric**: Usuario completa ≥3 tests

---

### A2: EL PLAN (4 semanas)
**Objetivo**: "Diseña tu transformación"

**User Journey**:
1. Llega a A2 (hero section clara: "Tu plan de 90 días")
2. Coach lo guía a crear MISIÓN personal:
   - "¿Dónde quieres estar en 90 días?"
   - Basado en su A1 + su visión
3. Sistema genera:
   - Sprint 1-4 (acciones concretas)
   - Hitos semanales
   - Check-ins con Coach
4. **Bitácora** (innovación): Diario de progreso
   - 1 entrada diaria (5 min)
   - Sistema aprende de patrones
   - Coach ofrece insights
5. Dashboard con:
   - Misión destacada
   - Sprint actual
   - Progreso visual
   - Estadísticas (acciones completadas, streak)

**Diseño UX**:
- Barra lateral con Coach disponible
- Sprints como tarjetas interactivas
- Bitácora accesible (botón grande)
- Métricas simples y motivantes

**Success Metric**: Usuario completa Sprint 1 + 7+ entradas en Bitácora

---

### A4: LA REALIDAD (4 semanas, paralelo con A2)
**Objetivo**: "Entiende tu contexto"

**User Journey**:
1. A4 aparece como opción desde A2 (no es mandatorio, pero recomendado)
2. Dashboard A4 con 3 pilares:
   - **Noticias**: Feed de contexto relevante
   - **Cultura General**: Tests sobre mercado (10-15 min c/u)
   - **Biblioteca**: Recursos curados (artículos, podcasts, libros)
3. Coach explica noticias: "¿Por qué importa esto para ti?"
4. Usuario acumula puntos y badges
5. Integración con A2:
   - "Tu contexto sugiere estas acciones en Sprint 2"

**Diseño UX**:
- Tabs claros: Noticias | Tests | Biblioteca
- Noticias con resumen + relevancia
- Tests gamificados (no evaluativos)
- Recursos con metadatos y enlaces

**Success Metric**: Usuario lee 5+ noticias + completa 1 test

---

### A3: LA PRÁCTICA (8 semanas)
**Objetivo**: "Practica siendo quien quieres ser"

**User Journey**:
1. Llega a A3 (solo si completó Sprint 1 de A2)
2. Dashboard muestra:
   - Tu misión A2
   - Tu contexto A4 relevante
   - Entrenamientos personalizados
3. Tipos de entrenamientos:
   - Entrevistas simuladas (AI-powered)
   - Escenarios de trabajo real
   - Preguntas difíciles
   - Presentaciones
4. Cada entrenamiento:
   - Setup (contexto A4)
   - Simulación (interactiva)
   - Feedback instantáneo
   - Repetición (mejorar)
5. Coach acompaña: "Veo que mejoraste en X"

**Diseño UX**:
- Entrenamientos como "desafíos"
- Progreso visible
- Botón "Repetir" prominente
- Feedback constructivo (sin juzgar)

**Success Metric**: Usuario completa 3+ entrenamientos

## 3. PUNTOS DE FRICCIÓN A EVITAR

**❌ MAL: Usuario pierde el hilo**
```
A1 (tests) → A2 (plan) → A3 (entrenamientos)
Problema: User no entiende POR QUÉ hacer cada cosa
Solución: Contexto + coaching en cada transición
```

**✅ BIEN: Contexto + propósito claro**
```
A1 → "Ahora haremos un PLAN basado en tu perfil"
     ↓
A2 → "Al mismo tiempo, entiende el MERCADO (A4)"
     ↓
A3 → "Ahora PRACTICA con escenarios reales que viste en A4"
```

## 4. INTEGRACIÓN ENTRE FASES

### A1 → A2
- Coach resume A1: "Tu fortaleza es X, brecha es Y"
- Sistema sugiere primeras acciones en Sprint 1 basadas en A1
- Link directo "Ir a A2" desde resultados A1

### A2 ↔ A4
- A2 muestra sugerencia: "Lee esto en A4 para entender mejor"
- A4 muestra: "Esto conecta con tu misión en A2"
- Coach menciona ambos contextos

### A3 ← A2 + A4
- A3 simula escenarios que existen en A4 contexto
- A3 usa lenguaje y situaciones de A2 plan
- Coach conecta: "Practicaste esto en A2, ahora simúlalo"

## 6. ELEMENTOS DE UX ELEGANCIA

### Visual Hierarchy
- Cada fase tiene COLOR único
- A1 = Azul (autodescubrimiento)
- A2 = Verde (acción)
- A3 = Naranja (práctica)
- A4 = Cyan (conocimiento)

### Micro-interactions
- Cuando completa A1 → confetti + "¡Perfil completado!"
- Al iniciar A2 → transición suave + Coach mensaje de bienvenida
- En A3 → feedback visual instantáneo (barra de mejora)
- A4 → badges cuando alcanza hitos

### Momentum
- Cada fase termina con victoria (badge/stat)
- Siguiente fase empieza con propósito claro
- Coach siempre conecta el "por qué"

## 10. CASOS DE ÉXITO

**Caso 1: Usuario rápido**
- A1 (3 días) → A2 misión (día 5) → A4 noticias (día 7) → A3 entrenamientos (día 10)
- Timeline: 2 semanas para entrenamiento intensivo

**Caso 2: Usuario contemplativo**
- A1 (1 semana, todos tests) → A2 plan (2 semanas) → A4 contexto (2 semanas) → A3 (comienza semana 5)
- Timeline: 5 semanas para primer entrenamiento

**Caso 3: Usuario A2-only**
- A1 (rápido) → A2 plan + A4 contexto (4 semanas) → Salida sin A3
- Timeline: 4 semanas hasta plan ejecutable

## CONCLUSIÓN

El ciclo A1→A2→A3→A4 es elegante porque:

1. **Intuitivo**: Flujo lógico (autoconocimiento → plan → contexto → práctica)
2. **Elegante**: Sin fricción, con propósito claro en cada transición
3. **Fácil**: Usuario sabe qué hacer y por qué
4. **Certero**: Cada fase prepara la siguiente, acumulando transformación
5. **Diferenciador**: La integración A2+A4→A3 es única

El usuario no siente que está en "4 fases" sino en UN viaje coherente de 90 días hacia transformación profesional real.
