## Day Configuration Structure

Each day in `A2_DAYS` contains:

```typescript
interface A2Day {
  dia: number                        // Day number (1-90)
  title: string                      // Day title (Spanish)
  subtitle: string                   // Short subtitle/theme
  description: string                // Full description (100-200 words)
  phase: 'clarity' | 'material' | 'interview' | 'real-action' | 'refinement'  // Phase tag
  unlocksA3Module: string | null    // A3 module ID if unlocked, null otherwise
  tasks: string[]                    // 2-4 concrete tasks for the day
  learningGoals: string[]            // 2-3 learning outcomes
  actionItems: string[]              // 2-3 action deliverables
  notionTemplate: string             // URL to Notion template
  estimatedHours: number             // Time estimate (0.5-2.5 hours)
}
```

## Progress Tracking

The application includes:

- **A2 User Progress Table**: `a2_user_route_progress`
  - Tracks: `dia_actual` (current day 1-90)
  - Tracks: `tareas_completadas` (completed day IDs)
  - Enables: Day locking/unlocking, progression

- **Completion Status**: `A2CompleteDayButton` component
  - Marks day as complete
  - Updates database
  - Unlocks next day
  - Triggers A3 module unlocks if configured

- **Navigation**: Previous/Next day buttons
  - Day buttons navigate to /dia-{number}
  - Disabled if day not yet reached/current
